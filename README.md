# 🌌 Universe Website

My first ever website! 🚀

This was my first project when I started learning programming. I made a simple website about the universe using only HTML and CSS.

I wanted to make something about space, planets, the future, and all the interesting things beyond our world. So, I tried putting together some images, text, and styling to make a website of my own.

It wasn't anything big or complicated, but I was happy that I could actually make a website myself!

## 🌍 What is this website about?

The website is about the universe and space. It has information, pictures, and text about planets and the future.

I mainly focused on making the page look nice and arranging everything properly.

## 🛠️ What I used

- **HTML** — to add text, images, and content to the website.
- **CSS** — to add colors, styling, and make the website look better.

That's it! No JavaScript or complicated technologies, just HTML and CSS.

## 📚 What I learned

While making this project, I got my first experience with:

- Writing HTML to create a webpage.
- Using CSS to style a website.
- Adding images and text to a page.
- Understanding how websites are put together.
- Trying things out, making mistakes, and fixing them.

## 💭 Looking back

This project might look simple compared to the things I'm building now, but it will always be special because it was where I started.

I was just a beginner trying to learn how to code and make something on my own. I didn't know much back then, but this project helped me take my first step into web development.

Everyone starts somewhere, and this was my somewhere. 🌌
